# Nest & Coop Premium Showcase Web App

An ultra-sleek, end-to-end artisanal egg-showcase experience featuring clean 3D pure-CSS shape-shifting scroll choreographies.

## Features
- **Pure CSS Morphing Egg**: Transitions color profiles and surface micro-speckles based on scroll milestones.
- **Lenis Smooth Scroll**: Elegant momentum physics matching premium custom cursor depth trackings.
- **Micro-Cart Client Infrastructure**: Pure JS state management for basket selections.

## Local Execution
Simply load `index.html` within your preferred web browser. No compilation steps required!
